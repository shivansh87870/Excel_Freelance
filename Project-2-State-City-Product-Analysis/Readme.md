# Excel Project — State, City, and Product Sales Insights (10000+ records)

## Project Overview

This Excel project analyzes customer and product sales across different states and cities using Pivot Tables. The objective is to extract meaningful insights such as top-performing products, city-wise sales, and lowest-performing items in specific regions.

The analysis is structured into multiple business questions and solved using Excel data analysis techniques.

## Business Questions Solved

Q1. State-wise customer total sales
Q2. Top 5 product sales from the state of Florida
Q3. City-wise customer total sales
Q4. Bottom 3 product sales from the state of California

## Dataset Description

The dataset contains sales transaction data including:

* Customer Name
* State
* City
* Product Name
* Sales Amount
* Other transactional attributes

## Steps Performed

1. Data Cleaning

   * Checked data consistency
   * Verified numeric sales values
   * Ensured proper formatting

2. Data Analysis

   * Created Pivot Tables for each question
   * Grouped data by State and Customer
   * Filtered specific states (Florida & California)
   * Sorted sales values to identify Top and Bottom products

3. Data Aggregation

   * State-wise customer sales summary
   * City-wise customer sales summary
   * Top 5 products in Florida
   * Bottom 3 products in California

## Key Insights

* Customer sales vary significantly across states
* Florida shows strong performance in selected products
* California includes some low-performing products
* City-level analysis helps identify high-value customers
