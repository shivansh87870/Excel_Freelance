# Excel Data Analysis Project — Top 5 Cities by Sales

## Project Overview

This project focuses on analyzing sales data using Microsoft Excel to identify the Top 5 cities based on total sales. The dataset was cleaned, formatted, and analyzed to generate meaningful business insights and visualizations.

The final output includes a pivot table and chart that clearly highlight the top-performing cities.

## Objective

* Clean and format raw sales data
* Analyze sales performance by city
* Identify top 5 cities based on total sales
* Create a visual dashboard using Excel

## Dataset Features

The dataset contains the following fields:

* Country
* City
* Ship Mode
* Segment
* Sub-Category
* Quantity
* Discount
* Profit
* Sales

## Steps Performed

1. Data Cleaning

   * Checked for missing values
   * Ensured consistent formatting
   * Verified numeric fields

2. Data Formatting

   * Structured columns properly
   * Applied table formatting
   * Standardized headers

3. Data Analysis

   * Created Pivot Table
   * Aggregated Sales by City
   * Sorted values in descending order
   * Identified Top 5 Cities

4. Visualization

   * Created Bar Chart for Top 5 Cities
   * Added chart title and labels
   * Improved readability

## Key Insights

* Top-performing cities were identified based on total sales
* Sales distribution varies significantly across cities
* Visual dashboard provides quick decision-making support
